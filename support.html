Support

Need help with Auto Post Manager? Please use the project's GitHub Issues page to report a problem or ask a question.

Open a support request on GitHub

When reporting a problem

  • Describe what you were trying to do.
  • Include the error message and application version, if available.
  • Do not include passwords, access tokens, verification codes, or private account information.

We aim to review support requests and respond when possible.
